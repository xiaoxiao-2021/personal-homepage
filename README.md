# 个人首页 · Personal Homepage

一个用于个人日常工作的 Windows Electron 首页：按场景查看和完成任务、打开常用入口，用 AI 生成待确认的任务便签，并使用共用的时间、日历、本地音乐和番茄钟。

版本：**0.3.15**；构建标识：**2026.10.28.1**。项目由个人独立主导需求、设计取舍与使用验证，使用 ChatGPT / Codex 辅助编码和测试。

[项目介绍与下载](https://personal-homepage-xiaoxiao.lilac-venus-8349.chatgpt.site) · [Windows 测试版](https://github.com/xiaoxiao-2021/personal-homepage/releases/tag/v0.3.15-preview.1)

## 功能

- 总览、临床、科研、学习、生活五个场景，各自保存入口和任务视图。
- 软件、网站、文件和文件夹入口，支持搜索、右键操作和跨场景共享。
- 文件中转站：打开用户主动选择的文件夹，不自动清理或传输文件。
- 国内版滴答清单接入：全部日期或今天视图、稳定清单 ID 关联、离线缓存和异常提示。
- 用户明确启用写入授权后，可以从首页完成单个滴答任务及其有稳定 ID 的检查小项。
- DeepSeek 任务助手：自然语言描述 → 生成一张可编辑的浮动便签 → 核对后主动确认 → 创建到滴答并刷新任务区。
- 共用时钟、跟随今天的月历、本地音乐播放和紧凑番茄钟。
- 可选的只读 Codex 额度卡片：显示官方接口返回的额度窗口、自然刷新时间、剩余重置次数及到期信息；缺失字段保持未知。
- 布局编辑、保存与取消、主题、壁纸、配置备份和恢复。
- 单实例、托盘、快捷键，以及用户可选择的登录启动和可退出桌面层试验。

## 运行

免安装测试版：到 Releases 下载 ZIP，完整解压后双击“个人首页.exe”。不要只复制 exe，也不要覆盖原来的源码目录。测试版未进行本项目发布者签名，图标和文件属性仍保留部分 Electron 元信息；请核对来源和校验值，不要关闭系统安全软件。可用 `npm run build:portable` 在已安装依赖的 Windows x64 源码目录离线重新构建；旧构建不会被覆盖。

以下是**从源码运行**的方式：

仅面向 Windows 桌面环境。需要先安装 Node.js 和 npm，然后在项目目录运行：

```powershell
npm ci
npm run check
npm start
```

依赖安装完成后，也可以双击 `启动个人首页.cmd`。Git 源码树不包含 Electron 二进制、node_modules 或安装包；二进制测试包单独放在 Releases。

登录启动默认不自动写入，由用户在软件设置中明确开启。若启用，保持项目位置稳定；移动程序后需由用户更新本软件启动设置。

注意：本项目的用户配置由 Electron 的 userData 管理。同名应用的两个源码副本可能共用本机配置；不要用正常启动来做隔离测试。测试程序使用独立配置或合成数据。

更新已有运行实例时，请先保存或取消编辑，从托盘完全退出，再使用原启动入口打开，并在设置中核对构建标识。不要同时启动多个源码副本来比较版本。

## 滴答权限和数据

使用国内滴答的官方 OAuth 与 Open API。默认申请 `tasks:read`；需要完成任务、勾选检查小项或确认创建任务时，由用户明确启用 `tasks:write`。本软件不提供任意任务删除或通用任务编辑。

完成成功后才更新列表；失败时保留任务并提示。重复任务及含未完成检查项的父任务先确认；下一次重复安排由滴答服务返回。离线不排队提交，网络结果未知时应先刷新核对。本页不提供撤销完成，误操作请在滴答客户端恢复。

检查小项采用独立的较小方框，保留更大的点击区域与键盘聚焦提示。提交前读取最新父任务，通过稳定小项 ID 更新目标并回读核对，不自动完成父任务。由于接口需要提交父任务的相关字段及检查项数组，其他客户端在读取与提交之间并发修改仍存在竞争窗口，建议避免同时编辑同一任务。

授权令牌和任务缓存使用 Windows 系统保护加密保存在本机，不包含在源码仓库。布局备份不包含凭据。软件只处理用户主动选择的入口、壁纸和音频，不扫描磁盘或上传本地素材；保留路径禁区、符号链接和快捷方式安全校验。

官方文档：https://developer.dida365.com/docs/openapi.md

## 任务助手

在任务助手的“配置”中填写自己的 DeepSeek API Key，并选择受支持的模型。API 按服务商规则单独计费；保存设置不发送请求，测试连接和发送消息可能产生费用。首页只将本次任务描述、必要的对话上下文和候选清单等信息发送到 DeepSeek，不自动上传整份任务库或本地文件。

输入安排后，先检查浮动便签上的标题、明确日期、时间、清单和备注；可直接编辑或返回聊天纠正。只有主动点击“添加到滴答”才创建任务，生成或关闭便签不会写入。若请求结果未知，先到滴答核对，不反复创建。

密钥由 Windows 加密单独保存在本机，页面不会回显已保存密钥，也不进入普通配置、布局备份或仓库。聊天和草稿只保留在本次运行中；创建不确定状态另行加密保存，避免重启后盲目重复提交。

## 共用工具区

五个场景共用一份工具设置。在“编辑布局 → 管理模块”中调整显隐、顺序、尺寸和折叠，纳入保存／取消流程；当前场景的任务与入口仍各自独立。“项目与资料”保留在中间入口区下方，可单独显示或隐藏，隐藏不会删除入口或本地文件。

- 日历默认跟随本地今天；手动翻月或选日期后保持浏览，点击“今天”恢复跟随。
- 音乐只播放主动添加的本地音频；切换场景或折叠不停止播放，重启默认暂停。
- 番茄钟默认专注 25 分钟、休息 5 分钟，支持开始、暂停、继续、重置及单独保存时长；完全退出后重启待机。
- Codex 额度需要本机已安装并登录官方 Codex 原生程序，兼容性取决于该程序的 App Server 接口。首页不直接读取令牌文件、不代为登录、不发送模型消息，也不使用重置机会。接口未提供的信息不推算。

宽窗口采用三列布局；右侧优先在可用高度内显示，内容多时内部滚动。窄窗口恢复自然排列，不为对齐底边强行拉高日历，也不改写保存的尺寸偏好。

## 已知限制

- 桌面层属于可退出的试验功能，不替换 Windows 系统外壳。
- 提供 Windows x64 免安装测试包，不提供安装向导或自动更新。免安装测试版的登录自启动暂时禁写，源码版原有能力保留。
- 本地音频支持范围取决于 Electron / Chromium 解码能力。
- 指定清单不等同于自动识别滴答真实收集箱。
- 检查小项是任务内的 `items`，不等同于任意层级的独立子任务树；首页不提供撤销完成。
- AI 可能理解错误，便签必须人工核对；不会自动纠正已经创建的真实任务。
- Codex 额度查询失败不代表剩余额度为零，不保证官方所有版本均返回相同字段。
- 长期运行、不同 Windows 环境和真实系统操作需要持续验证。
