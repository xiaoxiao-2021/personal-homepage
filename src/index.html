数据与权限说明

默认仅申请 tasks:read；只有用户明确启用完成任务时才申请 tasks:write。授权令牌使用 Windows 系统保护加密保存在本机，不写入页面、布局配置、备份或普通日志。本软件仅提供单任务完成，不提供编辑、删除或新建操作。重复任务与父任务会先确认；离线不提交。离线缓存会明确标出最近完整成功同步时间。

首页是普通本地应用与可退出的桌面层试验；不会替换 Windows 系统外壳。更改壁纸只作用于首页。桌面图标和文件不会被移动或整理。

登录启动与版本

默认不启用。登录启动只管理个人首页自己的当前用户启动项，不需要管理员权限。

正在读取 Windows 登录启动状态…桌面首页会先加载本地界面与配置，再有限等待 Explorer；失败时以普通窗口恢复。若 Windows 在任务管理器中禁用了此项，软件会如实提示，不会自动绕过。

启用首页完成任务

现有授权可以继续只读使用。启用完成需要你在滴答官方授权页明确同意 tasks:read 与 tasks:write。写入权限的授权范围不只限于完成，但首页仅提供完成操作，不提供新增、编辑或删除。

授权失败保留原有本机授权。完成后没有本页撤销功能；重复任务由滴答生成下一次安排。离线时不排队提交。
