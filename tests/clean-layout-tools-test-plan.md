# 清爽布局与共用工具区：最小回归方案

本方案只使用隔离配置、合成入口和内存中的静音音频；不读取正式任务、用户音乐、授权、缓存或启动项。

## 一个真实页面测试覆盖的主路径

建议新增 `tests/clean-layout-tools-ui.cjs`，沿用 `ui-smoke-preload.cjs`，由真实 `BrowserWindow` 加载 `src/index.html`。测试必须等待 `homeApi.pageReady()`，同时收集 `did-fail-load`、`render-process-gone`、页面 `error` 和 `unhandledrejection`。

1. **清爽布局取消**
   - 正常点击“编辑布局”，再点击“预览清爽布局”。
   - 断言当前场景的 `side` 被隐藏、`apps` 高度为 `content`，入口顺序、入口尺寸、任务高度均未改变。
   - 断言另一个场景完全没有变化。
   - 点击“取消”，断言当前场景完整恢复，且独立歌单状态未被回退。

2. **清爽布局保存和重开**
   - 再次从 UI 预览，点击“保存布局”。
   - 测试 IPC 将配置实际写到隔离 JSON 文件，而非只返回模拟成功。
   - 重新加载页面，断言 `side` 仍隐藏、`apps` 仍为 `content`，其他场景和共用工具未被改写。

3. **项目资料加入常用入口时复用 ID**
   - 使用一个同时具有 `library[id]` 和 `side` 引用、但尚不在 `apps` 的合成入口。
   - 从该资料入口的实际菜单选择“加入常用入口”。
   - 断言 `apps` 增加的值与原 `side` 引用 ID 完全相同；`library` 键数量不变；原 `side` 引用仍存在。
   - 再次执行时不得产生重复 ID。
   - 保存并重载后再次验证。

4. **共用工具个性化**
   - 从“管理模块”真实选择强调色、12/24 小时、时间字号、日历密度与音乐折叠状态。
   - 切换五个场景，断言读取的是同一份全局工具配置，不产生五份副本；同一个 `#musicAudio` 与日历 DOM 节点保持身份不变。
   - 取消一次并验证回退；保存一次并重载验证持久化。

5. **日期时间与音乐空状态**
   - 歌单为空时，只显示简洁的添加入口；播放、进度、时长等无效控制不应占据可见布局。
   - 12/24 小时切换应改变格式设置，不依赖测试执行时刻的具体数字。
   - 时间和日历同时显示时属于同一视觉组；隐藏任意一个时不留下空占位。
   - 日历保持 28/30/31 天及六行月份的既有几何测试，不需要重复穷举业务算法。

6. **三栏、两栏、单栏**
   - 用同一配置依次设置窗口内容宽度为 `1440`、`900`、`590` CSS px。
   - 断言无横向溢出、可见卡片互不相交。
   - 1440：工具区位于右侧；900：工具区占下一整行；590：任务、入口、可选资料、工具按垂直顺序排列。
   - 仅验证 CSS 响应式布局，不称为真实 Windows DPI 或桌面挂载验收。

## 不重复执行的既有覆盖

- `visual-polish-ui.cjs` 已覆盖基本保存失败、取消、重开与三种宽度。
- `responsiveness-ui.cjs` 已覆盖同一日历/音频 DOM 跨场景复用和静音合成音频播放。
- `shared-tools-state.cjs` 已覆盖旧生活场景工具配置向全局配置迁移。

新测试只补本轮新增行为，并在报告中明确：模拟系统 API、没有真实 Windows 桌面挂载、没有读取正式任务和用户音乐。

## 运行方式

静态/状态测试可直接运行：

```powershell
node tests\shared-tools-state.cjs
node tests\shared-tools-ui.cjs
```

真实 Electron 页面测试需要在允许 GUI 进程的环境中运行：

```powershell
node_modules\electron\dist\electron.exe tests\clean-layout-tools-ui.cjs
```

测试程序应将报告和截图写入 `test-results\clean-layout-tools\`，使用独立 `userData`，不得读写正式配置。
